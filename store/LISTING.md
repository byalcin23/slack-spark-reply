# Spark Reply — Chrome Web Store listing

Status: release copy prepared, not submitted or approved. Product name is confirmed for this build; no trademark clearance claim is made.

## English

**Name:** Spark Reply

**Short description (102 characters):**

Draft thoughtful Slack replies with context, tone choices, and your own OpenAI API key. You choose what to send.

**Detailed description:**

Spark Reply helps you draft replies inside Slack on Chrome.

Open the sparkle beside the message box, review the visible conversation context, and add what you want to say. Generate three reply options, then copy one or place it into your Slack draft. You review and send the final message yourself.

Features:

- Reply suggestions based on the messages you select.
- Short, friendly, and professional variations.
- A note field for your intended meaning.
- Interface and reply language controls.
- Light, dark, and system themes.
- Connection and preferences in the same panel.

Connection and costs:

You need your own OpenAI API key and an OpenAI API account with available usage. API usage is billed separately by OpenAI. Spark Reply connects directly to OpenAI; no companion application, local server, or pairing code is needed. Your key is kept for the current Chrome session and must be entered again after Chrome restarts or the extension reloads.

Data handling:

When you request suggestions, your Slack identity (display name and available member ID), selected message text and sender identities, your current draft, and your note are sent to OpenAI. Review the context before generating and use the extension only where you are allowed to share that content. Spark Reply does not operate a service that receives your conversations and does not include advertising or analytics.

Scope:

Works with Slack's web application in Chrome. It uses a limited selection of messages currently visible on screen; it does not retrieve full channel history, attachments, or linked documents. AI suggestions can be inaccurate. Spark Reply never sends Slack messages automatically.

Spark Reply is an independent extension and is not affiliated with or endorsed by Slack or OpenAI.

## Türkçe

**Ad:** Spark Reply

**Kısa açıklama:**

Slack'te konuşma bağlamına uygun cevap taslakları hazırla. Kendi OpenAI API anahtarınla çalışır; son kararı sen verirsin.

**Ayrıntılı açıklama:**

Spark Reply, Chrome'daki Slack konuşmalarına cevap yazmana yardımcı olur.

Mesaj kutusunun yanındaki parıltı simgesine bas, ekranda görünen konuşma bağlamını kontrol et ve ne söylemek istediğini ekle. Üç cevap seçeneği üret; seçtiğini kopyala veya Slack taslağına ekle. Son mesajı sen kontrol edip gönderirsin.

Özellikler:

- Seçtiğin mesajlara göre cevap önerileri.
- Kısa, samimi ve profesyonel alternatifler.
- Ne anlatmak istediğini yazabileceğin not alanı.
- Arayüz ve cevap dili seçenekleri.
- Açık, koyu ve sistem teması.
- Aynı panelden bağlantı ve tercih yönetimi.

Bağlantı ve ücretler:

Kendi OpenAI API anahtarın ve kullanıma açık bir OpenAI API hesabın gerekir. API kullanımı OpenAI tarafından ayrıca ücretlendirilir. Spark Reply doğrudan OpenAI'ye bağlanır; ek uygulama, yerel sunucu veya eşleştirme kodu gerekmez. Anahtarın mevcut Chrome oturumunda tutulur; Chrome yeniden başladığında veya eklenti yeniden yüklendiğinde tekrar girmen gerekir.

Veriler:

Öneri istediğinde seçtiğin mesajlar ve gönderen adları, mevcut taslağın ve notun OpenAI'ye iletilir. Göndermeden önce bağlamı kontrol et ve yalnızca paylaşmaya yetkili olduğun içerikleri kullan. Spark Reply konuşmalarını alan bir sunucu işletmez; reklam veya kullanım analitiği içermez.

Kapsam:

Chrome'daki Slack web uygulamasıyla çalışır. Ekranda görünen sınırlı sayıdaki mesajı kullanır; kanalın tüm geçmişini, ekleri veya bağlantılı belgeleri getirmez. Yapay zekâ önerileri yanlış olabilir. Spark Reply Slack mesajlarını otomatik göndermez.

Spark Reply bağımsız bir eklentidir; Slack veya OpenAI ile bağlantısı ya da bu şirketlerin onayı yoktur.
