OpenAI API bağlantısı

Bu Mac’teki yardımcı, API anahtarını kullanarak cevap üretir. Anahtarını girip bağlantıyı test et; başarılı olduğunda Slack’teki ✦ panelini kullanabilirsin.

Eklenti ayarlarında kullandığın aynı kod. Ayarlardaki “OpenAI bağlantısını kur” düğmesinden geldiysen otomatik doldurulur. Boşsa start.command ile açılan Terminal penceresinden kopyala.

Bağlantı durumu kontrol ediliyor…

Test, OpenAI’a örnek bir konuşma gönderir ve API kullanımı oluşturur. Gerçek Slack konuşması kullanılmaz. Daha sonra Slack’te “Cevap öner” seçtiğinde seçili bağlam OpenAI’a gönderilir.

Anahtar bu Mac’te yalnızca kullanıcı hesabının okuyabildiği yerel bir dosyada saklanır; eklentiye veya sohbetimize kaydedilmez.
